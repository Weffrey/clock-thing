The linux application is a floating stopwatch/timer (no actual clock hence the name Clock Thing)

Thec controls are the following:

- Start/Stop: Left click
- Reset: Right click

Timer Specific:
Scroll up/down to remove/add time to timer, default time when opening is 10 minutes

Press 'r' to swtich between modes

Stopwatch/Timer don't keep running if the app's window closes, maybe change later?
